# 📦 ใบปะหน้าพัสดุ 4×6 (Thai Shipping Label Maker)

หน้าเว็บสำหรับพ่อค้าแม่ค้าออนไลน์ — วางที่อยู่ลูกค้าบรรทัดเดียว ระบบแยก **ชื่อ / เบอร์โทร / ที่อยู่ / ตำบล / อำเภอ / จังหวัด / รหัสไปรษณีย์** ให้อัตโนมัติ แล้วปริ้นใบปะหน้าขนาด **4×6 นิ้ว** พร้อมเก็บข้อมูลออเดอร์ลง **Excel** ให้เอง

ทำงานในเครื่องทั้งหมด ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่อเน็ต ข้อมูลลูกค้าไม่ถูกส่งไปที่ไหน

<img src="docs/label-example.png" width="260" alt="ตัวอย่างใบปะหน้า">

## ความสามารถ
- ✂️ **แยกที่อยู่อัตโนมัติ** จากข้อความบรรทัดเดียว (รองรับ กทม./ต่างจังหวัด, อ.เมือง, เบอร์ +66, ข้อความหลายบรรทัด) ใช้ฐานข้อมูลตำบลทั่วประเทศ 7,400+ รายการ
- 🔎 ค้นหา ตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์ แบบพิมพ์แล้วเลือก
- 🏷️ ชื่อผู้ส่งตั้งได้ 3 ชื่อ (ที่อยู่ใช้ร่วมกัน) เลือกได้ทุกออเดอร์
- 🖨️ ใบปะหน้า 4×6 นิ้ว ตัวอักษรใหญ่ อ่านง่าย เหมาะกับเครื่องปริ้นความร้อน ปริ้นทีละใบหรือหลายใบพร้อมกันได้
- 📊 บันทึกลงไฟล์ Excel อัตโนมัติ (ชีต "ออเดอร์" + "สรุปรายเดือน")
- 📝 กรอก ชื่อสินค้า, ยอดขาย, และกรอก **เลขพัสดุ / ค่าส่ง ภายหลัง** ได้ในแท็บ "รายการออเดอร์"
- 👋 จำลูกค้าเก่าจากเบอร์โทร กดใช้ที่อยู่เดิมได้ทันที

## วิธีติดตั้ง (Windows)
1. กดปุ่มสีเขียว **Code → Download ZIP** แล้วแตกไฟล์ไว้ที่ไหนก็ได้ (เช่น `D:\ShippingLabel`)
2. ดับเบิลคลิก **`create-desktop-shortcut.bat`** → จะได้ไอคอน **Shipping Label 4x6** บนหน้า Desktop
   (หรือเปิด `index.html` ด้วย Chrome / Edge ตรงๆ ก็ได้)
3. เปิดครั้งแรกจะมีหน้าตั้งค่าขึ้นมา
   - กรอก **ชื่อผู้ส่ง** (ได้สูงสุด 3 ชื่อ), **ที่อยู่ผู้ส่ง**, **เบอร์โทร** แล้วกด "บันทึกการตั้งค่า"
   - กด **"สร้างไฟล์ Excel ใหม่"** แล้วเซฟไว้ในโฟลเดอร์ `data`

> Mac / Linux: เปิด `index.html` ด้วย Chrome หรือ Edge ได้เลย (ไฟล์ .bat ใช้ได้เฉพาะ Windows)

## ตั้งค่าเครื่องปริ้น
| ตั้งค่า | ค่า |
|---|---|
| ขนาดกระดาษ | 4×6 in (100×150 mm) |
| ระยะขอบ (Margins) | None / ไม่มี |
| Scale | 100% |
| Headers and footers | ปิด |

## ข้อควรรู้
- ต้องใช้ **Chrome หรือ Edge** ถึงจะบันทึก Excel อัตโนมัติได้ (Firefox/Safari ใช้ปุ่ม "ดาวน์โหลด Excel" แทน)
- ถ้าเปิดไฟล์ Excel ค้างไว้ ระบบจะเขียนไม่ได้ (จุดด้านบนเป็นสีแดง) → ปิด Excel แล้วคลิกจุดแดงเพื่อบันทึกใหม่
- ข้อมูลเก็บในเบราว์เซอร์ + ไฟล์ Excel ถ้าล้างข้อมูลเบราว์เซอร์ ใช้ "เลือกไฟล์ Excel เดิม" เพื่อดึงข้อมูลกลับ
- ไฟล์ `.xlsx` ถูกตั้งค่าไม่ให้อัปโหลดขึ้น GitHub (`.gitignore`) เพื่อปกป้องข้อมูลลูกค้า

## โครงสร้างไฟล์
```
index.html                    หน้าเว็บหลัก
app.js                        โค้ดทั้งหมด (แยกที่อยู่, ปริ้น, Excel)
lib/thai-address-data.js      ฐานข้อมูล ตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์
lib/xlsx.full.min.js          SheetJS สำหรับเขียนไฟล์ Excel
lib/make-shortcut.ps1         สคริปต์สร้างไอคอนบน Desktop
fonts/                        ฟอนต์ Sarabun (ใช้ offline)
data/                         ที่เก็บไฟล์ Excel ของคุณ
create-desktop-shortcut.bat   ดับเบิลคลิกเพื่อสร้างไอคอน
```
