ใบปะหน้าพัสดุ 4x6 — วิธีใช้
================================

เริ่มต้น (ทำครั้งเดียว)
1) (Windows) ดับเบิลคลิก  create-desktop-shortcut.bat  → จะได้ไอคอน "Shipping Label 4x6" บนหน้า Desktop
2) เปิดโปรแกรมจากไอคอนนั้น (เปิดด้วย Microsoft Edge) หรือเปิด index.html ด้วย Chrome / Edge
3) ครั้งแรกจะมีหน้าตั้งค่าขึ้นมา → กรอกชื่อ ที่อยู่ เบอร์โทรผู้ส่ง แล้วกด "สร้างไฟล์ Excel ใหม่" แล้วเซฟไว้ในโฟลเดอร์ data
   (ถ้ามีไฟล์เดิมอยู่แล้ว ใช้ "เลือกไฟล์ Excel เดิม" ระบบจะดึงข้อมูลเก่ากลับมาด้วย)
4) แก้ชื่อผู้ส่ง (ได้ 3 ชื่อ) ภายหลังได้ที่ปุ่ม ⚙ ตั้งค่า (ที่อยู่ผู้ส่งใช้ร่วมกัน)

ใช้งานประจำวัน
- วางข้อมูลลูกค้าบรรทัดเดียวในช่อง "ป้อนอัตโนมัติ" → ระบบแยก ชื่อ / เบอร์ / ที่อยู่ / ตำบล / อำเภอ / จังหวัด / รหัสไปรษณีย์ ให้
- ตรวจดูตัวอย่างใบปะหน้าด้านขวา → กด "บันทึก & ปริ้นใบปะหน้า" (หรือ Ctrl+P)
- ข้อมูลถูกบันทึกลงไฟล์ Excel อัตโนมัติ (ชีต "ออเดอร์" + "สรุปรายเดือน")
- หลังส่งของแล้ว ไปที่แท็บ "รายการออเดอร์" → กรอกเลขพัสดุ และค่าส่ง ในตารางได้เลย
- ปริ้นซ้ำ / ปริ้นหลายใบพร้อมกัน: ติ๊กเลือกในแท็บ "รายการออเดอร์" แล้วกด "ปริ้นที่เลือก"

ตั้งค่าเครื่องปริ้น
- ขนาดกระดาษ: 4x6 in (100 x 150 mm)
- ระยะขอบ (Margins): None / ไม่มี
- Scale: 100% (ไม่ย่อ/ขยาย)
- ปิด "Headers and footers"

ข้อควรรู้
- ถ้าเปิดไฟล์ Excel ค้างไว้ ระบบจะเขียนไม่ได้ (จุดด้านบนจะเป็นสีแดง) → ปิด Excel แล้วคลิกจุดแดงเพื่อบันทึกใหม่
- ข้อมูลเก็บในเบราว์เซอร์ด้วย ถ้าล้างข้อมูลเบราว์เซอร์ ให้ใช้ "เลือกไฟล์ Excel เดิม" เพื่อดึงข้อมูลกลับ
- ต้องใช้ Chrome หรือ Edge (Firefox ไม่รองรับการเขียนไฟล์ Excel อัตโนมัติ — ใช้ปุ่ม "ดาวน์โหลด Excel" แทน)
